# Project Boundaries

This setup phase is intentionally limited.

## Included now

- Next.js project base.
- TypeScript and Tailwind configuration from `create-next-app`.
- Minimal empty app route.
- Documentation for context and structure.
- Environment variable template.
- Database schema and starter seed data.
- Empty folders for future shared code.

## Not included yet

- Functional landing page.
- Auth UI or auth flow.
- Dashboard.
- Interview simulator.
- AI interaction flow.
- Production billing flow.
- Reusable product components.
